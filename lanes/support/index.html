Lanes support

iPhone, Mac, Android, web · Private beta (TestFlight)

What it is

Lanes is a personal dashboard for running several Claude Code projects. It shows how full each project's task list is, what is waiting on the owner, and lets you read and reply to your Claude Code chats from your phone. It only works with a Lanes server that the owner runs on their own Mac.

It is a private beta shared through TestFlight and is used by its developer.

Getting started

  1. Install the app from the TestFlight invitation.
  2. Pair with the setup link or QR code the owner gives you. There is no account to create.
  3. Allow notifications if you want alerts when a project or chat needs you.
  4. Browse your projects on the main screen and open the Claude tab to read or reply to chats.
  5. If something goes wrong, open the Help screen and follow its self-checks.

Common questions

Do I need an account?

No. Lanes has no accounts, email or passwords. Pair with the setup link or QR code the owner gives you.

The app says it can't reach the server.

Check that your Mac and your phone are online. On iPhone and Mac, use the Can't reach the server button to send an encrypted report to the developer, or open Help and use Send to support. You see a Help report before it is sent. On Android the app only shows that the server can't be reached.

Is what I type being recorded?

By design, no. The usage logs are built to keep only the name of the field and how long the text is. Secure fields show as dots.

How do I remove everything Lanes saved on my device?

On iPhone and Mac, go to Settings and choose Erase All Data on This Device. On Android, use Forget this server in Settings and clear the app's storage in Android settings. Your Mac and other devices are not touched.

Where do my logs go?

On iPhone and Mac, to the developer's own server, which is the same server the app is paired with, and they are kept for 30 days. The Android app keeps its log on the phone only.

Still stuck?
