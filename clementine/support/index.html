Clementine support

Mac · Not on the App Store yet

What it is

Clementine converts pictures, videos, audio and PDFs into other formats on your Mac. The original file is not changed. The new file appears next to it.

It converts pictures (PNG, JPEG, HEIC, AVIF, WebP, PDF) and can resize, compress, crop, rotate and remove location info. For video it makes MP4, MOV, GIF or audio only, and can compress or mute. Audio goes to M4A, MP3, WAV or FLAC. For PDFs it can turn pages into pictures, pull out text, merge, split or compress.

Getting started

  1. Find the orange circle at the edge of the screen, or the Clementine icon in the menu bar.
  2. Drop a file on the circle or the icon. A ring of choices pops up.
  3. Click the format or action you want.
  4. Or hold Shift while dragging a file anywhere on screen, and let go on a choice in the ring. Hold Option instead to get the tools.
  5. Find the new file next to the original.

Common questions

Does Clementine upload my files?

No. Conversion happens on your Mac, and the app is designed not to upload anything.

Will it change my original file?

No. It saves a new file next to the original and leaves the original as it was.

Where are the logs?

In your Mac's Logs folder, in a folder named Clementine, with one file per day. You can also open Logs from the menu-bar icon.

How do I remove everything the app saved?

Open Settings and choose Erase All Data on This Device. Your converted files and originals are not deleted.

Can I use it from Terminal?

Yes. There is a command-line tool called clem. Run it with the list command and a file to see what that file can be converted to.
